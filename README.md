# 📊 Analiza danych sprzedażowych

Projekt polega na analizie danych sprzedażowych przy użyciu **Python + Pandas + Matplotlib**.

---

## 🗂️ Zawartość projektu

- `sales_data.csv` – przykładowy plik z danymi (data, produkt, ilość, cena, przychód)
- `dashboard.py` – skrypt analizujący dane i generujący wykresy
- `wykresy/` – folder z zapisanymi wykresami (automatycznie generowany)

---

## 📈 Wygenerowane wykresy

1. **Top 5 produktów wg przychodu** (`top_produkty.png`)  
2. **Przychód miesięczny** (`przychody_miesieczne.png`)
3. **Ilość sprzedanych sztuk wg produktu** (`ilosc_sztuk.png`)
4. **Średnia cena sprzedaży wg produktu** (`srednia_cena.png`)

---

## 🛠️ Technologie

- Python 3.x
- Pandas
- Matplotlib

---

## 🚀 Jak uruchomić

1. Zainstaluj wymagane biblioteki:

pip install pandas matplotlib

2. Uruchom skrypt:

python dashboard.py+

3. W folderze `wykresy/` znajdziesz wygenerowane wykresy.
